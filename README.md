# Apollo AGC Lab

Gamified learning app built on the real Apollo Guidance Computer — trace bits and assembly through to flight.

## What this is

A personal learning project (for David first, non-money) about the Apollo Guidance Computer (AGC): the computer that navigated and flew the Apollo Command and Lunar Modules.

The goal is to *understand* the real machine — how its components work, how its code works — and to explore turning that understanding into a gamified learning app. The fascination is two-sided:

- How advanced the AGC was for its time, yet how primitive it is next to a modern phone.
- That it really was just numbers — zeros and ones — compiled all the way through to do actual, physical things: display a value, fire an engine, turn a spacecraft. The synthesis between hardware and software.

Nothing is built yet. This repo starts docs-first: spec, learning map, and feasibility notes before any code.
